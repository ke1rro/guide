# Ubuntu x86_64 через UTM Emulate

Цей варіант може бути надійнішим для перевірки коду саме в x86_64 середовищі,
Водночас ARM64 Ubuntu через Apple Virtualization теж хороший варіант. Особисто я б спочатку спробував [ARM64 setup через `Virtualize`](arm64.md), а далі обрав би те, з чим вам зручніше працювати.

ARM64 Ubuntu Desktop через `Virtualize` зазвичай займає більше місця, тоді як
x86_64 Ubuntu Server тут легший за RAM і storage, бо працює без desktop GUI.

Тут використовується Ubuntu Server без desktop GUI. Працювати з VM зручно через
SSH і VS Code з розширенням
[Remote - SSH](https://code.visualstudio.com/docs/remote/ssh).

> [!NOTE]
> Емуляція x86_64 на Apple Silicon повільніша за ARM64 virtualization. У мене
> встановлення Ubuntu Server і підключення через VS Code зайняли понад годину.

## 1. Завантажте Ubuntu Server для x86_64

Завантажте актуальний LTS-образ Ubuntu Server для архітектури `amd64` з
[офіційної сторінки Ubuntu](https://ubuntu.com/download/server).

## 2. Створіть VM в UTM

У UTM натисніть `+` і виберіть `Emulate`.

![Вибір Emulate](../.github/imgs/x86-64/utmx86-1.png)

Потім виберіть `Linux`.

![Вибір Linux](../.github/imgs/x86-64/utmx86-2.png)

У Hardware залиште `Intel ICH9 based PC (2009, x86_64)`. Для Ubuntu Server не
обовʼязково виділяти стільки ж ресурсів, як для ARM64 Ubuntu Desktop: можна
почати з `2048–4096 MiB` RAM і `2` CPU cores. На скріншоті я використовую
`4096 MiB`.

![Налаштування hardware для x86_64](../.github/imgs/x86-64/utmx86-3.png)

Оберіть `Boot from ISO image` і вкажіть завантажений x86_64 Ubuntu Server ISO.

![Вибір ISO для Ubuntu Server](../.github/imgs/x86-64/utmx86-4.png)

Для цього Ubuntu Server setup не обовʼязково виділяти `64 GiB` диска. Я б
вибрав `25 GiB`; за потреби disk можна збільшити пізніше.

![Вибір розміру диска](../.github/imgs/x86-64/utmx86-5.png)

Завершіть створення VM і запустіть її.

## 3. Встановіть Ubuntu Server

Установник керується клавішами зі стрілками, `Tab`, `Space` та `Enter`.

Оберіть мову інсталятора.

![Вибір мови](../.github/imgs/x86-64/ub86-1.png)

Залиште потрібну розкладку клавіатури.

![Налаштування клавіатури](../.github/imgs/x86-64/ub86-2.png)

Для типу встановлення виберіть звичайний `Ubuntu Server`, не `minimized`.

![Вибір Ubuntu Server](../.github/imgs/x86-64/ub86-3.png)

У мережевому кроці DHCP зазвичай одразу покаже IPv4-адресу. Запамʼятайте її:
вона знадобиться для першого SSH-підключення.

![IPv4-адреса VM](../.github/imgs/x86-64/ub86-4.png)

Proxy залиште порожнім.

![Налаштування proxy](../.github/imgs/x86-64/ub86-5.png)

Mirror можна залишити типовим.

![Дзеркало пакетів Ubuntu](../.github/imgs/x86-64/ub86-6.png)

Для диска виберіть `Use an entire disk`. Це очищає лише віртуальний диск VM,
не диск Mac. LVM можна залишити увімкненим, шифрування для цього setup не
потрібне.

![Вибір диска](../.github/imgs/x86-64/ub86-7.png)

Перевірте схему розділів і натисніть `Done`.

![Підтвердження схеми диска](../.github/imgs/x86-64/ub86-8.png)

Підтвердіть початок встановлення. Воно видалить дані лише на віртуальному
диску, вибраному на попередньому кроці.

![Підтвердження форматування віртуального диска](../.github/imgs/x86-64/ub86-9.png)

Створіть користувача. Запамʼятайте username і пароль: вони потрібні для SSH та
команд через `sudo`.

![Створення користувача](../.github/imgs/x86-64/ub86-10.png)

Ubuntu Pro не потрібен, оберіть `Skip for now`.

![Пропустити Ubuntu Pro](../.github/imgs/x86-64/ub86-11.png)

У кроці SSH обовʼязково увімкніть `Install OpenSSH server`. Це дозволить
підключитися до VM з macOS. Для першого setup можна залишити ввімкненим
`Allow password authentication over SSH`.

![Встановлення OpenSSH server](../.github/imgs/x86-64/ub86-12.png)

Featured server snaps не потрібні, нічого не вибирайте й продовжуйте.

![Пропустити server snaps](../.github/imgs/x86-64/ub86-13.png)

Дочекайтеся завершення встановлення й виберіть `Reboot Now`. Не відʼєднуйте
ISO одразу: дочекайтеся повідомлення про вилучення installation medium. Тоді в
UTM відкрийте меню `Virtual Machine`, далі `Drives`, виберіть ISO і натисніть
`Eject`.
Поверніться в консоль VM, натисніть `Enter` і увійдіть під створеним
користувачем.

## 4. Підключіться з macOS через SSH

Потрібні три дані з інсталяції: username, пароль та IPv4-адреса VM. У Terminal
на Mac виконайте:

```bash
ssh <username>@<IPv4-адреса-VM>
```

Під час першого підключення підтвердіть fingerprint словом `yes`, потім введіть
пароль користувача VM.

![Підключення до Ubuntu Server через SSH з macOS](../.github/imgs/x86-64/connect-from-mackbook.png)

Якщо після reboot адреса змінилася, увійдіть у консоль VM і виконайте:

```bash
ip addr
```

Шукайте IPv4-адресу мережевого інтерфейсу, наприклад `enp0s1`.

## 5. Підключіться через VS Code

Установіть розширення `Remote - SSH` у VS Code. Відкрийте Command Palette,
оберіть `Remote-SSH: Connect to Host...` і введіть:

```text
<username>@<IPv4-адреса-VM>
```

Під час першого підключення VS Code встановить VS Code Server у VM. Після
цього можна відкривати папки, terminal і запускати код у x86_64 Ubuntu прямо з
VS Code на Mac.

Успішне підключення видно за позначкою `SSH: <IP-адреса-VM>` внизу ліворуч.
У домашній папці VM також зʼявиться `.vscode-server`.

![Успішне SSH-підключення у VS Code](../.github/imgs/x86-64/vscode1.png)

Через Remote Explorer можна бачити підключену VM, відкривати її домашню папку
та керувати SSH-підключенням.

![Remote Explorer з підключеною VM](../.github/imgs/x86-64/vscode2.png)

## 6. Оновіть систему та встановіть базові інструменти

Після першого входу через SSH виконайте:

```bash
sudo apt update
sudo apt upgrade
sudo apt install build-essential gdb
```

Тепер `gcc` і `g++` у цій VM створюють нативні x86_64 binaries.
